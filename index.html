USER GUIDE

操作与科学说明

视口操作

  • 左键拖拽 — 无死角轨道旋转（阻尼惯性）
  • 滚轮 — 透视模式改变距离 / 正交模式改变视口比例
  • 右键拖拽 — 平移视口
  • 点击器官 — 弧线运镜 + 景深聚焦 + 知识框架
  • 解剖剖面按钮 — 主干 / 根 / 叶代表性横切面，可切换分层爆炸图
  • 双击空白 / Esc — 返回全景；解剖视图内按 Esc 返回三维标本

建模口径

  • 物种：栽培苹果 Malus domestica Borkh.，蔷薇科苹果属
  • 分枝采用黄金角 137.5° 叶序 + 斐波那契级数递推节间，属参数化形态发生近似；真实分枝由顶端优势与激素调控，并非严格数学定律
  • 贴图为程序化生成的高分辨率 PBR 贴图集（漫反射 / 法线 / 粗糙度 / 位移），不依赖外部素材
  • 微观结构（气孔、绒毛、蜡质）为教学放大表达，非等比尺度
  • 解剖剖面为模式化教学切面：仅取主干、吸收根、叶片各一处代表性横断面，标注周皮 / 韧皮部 / 形成层 / 木质部 / 髓、凯氏带 / 中柱鞘、栅栏与海绵组织等，层厚按教学需要放大
  • 知识库内容依据果树栽培学通用结论整理，具体农事参数需按品种、砧木与当地气候校正

模块层级

  • 地下：主根 / 输导根 / 生长根 / 吸收根 / 根颈
  • 轴体：树干（树皮、形成层、年轮截面）
  • 冠层：中心领导干 / 一级主枝 / 二级侧枝 / 结果枝组 / 副梢
  • 叶器：叶片（叶肉、叶脉、气孔）/ 叶柄
  • 繁殖：叶芽 / 花芽 / 芽鳞 / 花瓣 / 雄蕊群 / 雌蕊 / 萼片
  • 果实：果体 / 果柄 / 梗洼 / 萼洼 / 表皮蜡质 / 果心种子

AI 接口

  • 兼容 OpenAI /chat/completions 协议，支持流式 SSE
  • 内置服务端代理 /api/ai，可用环境变量配置上游
  • 未配置或网络不可用时自动降级至内置离线知识库，并在界面明确标注来源
