# 课程助教知识库 · 说明与评审对照

> 苹果树 3D 数字孪生配套的课程问答能力。顶栏「课程助教问答」按钮进入（书本图标）。

## 一、定位与知识范围

| 项 | 内容 |
|---|---|
| 服务对象 | 修读《植物学》及园艺 / 果树类课程的学生，配合本 3D 苹果树标本学习器官与组织的形态解剖 |
| 使用场景 | 课前预习 / 课后复习与「复习思考·探究学习」作答；对照三维标本辨认器官与组织层次；实验课前查阅切片与显微结构的教材定义 |
| 资料来源 | **唯一事实依据**：《植物学（第三版）》，金银根 主编，科学出版社，全彩版，「十三五」规划教材，356 页。由用户提供的扫描版 PDF 经 OCR 转为全文（`knowledge/植物学（第三版）/`），再切成 905 个检索片段存于 `src/data/botany/` |
| 范围声明位置 | 界面说明卡常驻显示（服务对象 / 场景 / 三层范围 / 来源），口径取自 `src/services/BotanyRetriever.js` 的 `SCOPE` 常量，文档与界面同源 |

**三层知识范围**

- **核心**：苹果树已建模的 32 个部位及其组织 —— 根系（主根、输导根、生长根、吸收根、根毛、根颈）、主干（木质部、周皮、形成层、年轮）、冠层分枝、叶片与叶肉 / 叶脉 / 气孔 / 叶柄、芽、花器、果实与种子。
- **扩展**（「也可以放开一些」）：教材全本的植物学基础 —— 细胞与组织、营养器官与生殖器官、植物界基本类群与分类、被子植物主要分科、植物生理基本概念。
- **不回答**：教材未载的具体农事参数（品种 / 砧木配组、农药登记剂量与安全间隔期、当地栽培规程、实时测报）；非植物学问题；需要最新文献或教师判断的开放问题。

> 口径说明：三维标本「AI 解读」里的园艺实践条目来自果树学通用资料整理，**不是**这本教材的内容，界面已单独标注，课程助教不把它当依据。

## 二、知识准确性

| 机制 | 做法 |
|---|---|
| 检索增强（RAG） | 先按中文 2/3-gram + IDF 加权检索教材片段，再把片段原文注入模型。**提示词硬规则：只依据片段作答，禁止「补充 / 校正 / 深化」，禁止凭常识生成片段外的数据、术语、品种、剂量、文献** |
| 出处可回查 | 每条回答标注 `《植物学（第三版）》· 第X章 ·「小节」· 教材 Pxxx`；界面「查看教材依据」可展开原文片段；离线回答直接给原文摘录，不改写、不推断 |
| 页码可靠性 | OCR 页眉页码按目录给出的各章区间钳制校正（绪论 1–20 / 一章 21–83 / 二章 84–122 / 三章 123–189 / 四章 190–248 / 五章 249–360），905 个片段全部带页码 |
| 低置信拒答 | 首位得分低于阈值，或超过 0.72 相对分数下限的片段被剔除；检索无可靠结果时明确说「教材里没有找到足够可靠的依据」，不硬答 |
| 部位解读同源 | 点击三维器官后的「课本解读」标签与课程助教**共用同一条教材检索链**：先检索该部位对应的课本原文，离线直接显示原文摘录 + 章节页码；配置 AI 时只把这些片段交给模型组织表达，内置果树学条目仅作辅助线索、不作为教材依据引用 |
| 农事参数拦截 | 命中「喷多少 / 剂量 / 登记标签 / 稀释倍数」等操作词时直接拒答，并提示按登记标签、安全间隔期与农技部门意见执行 |
| 离线一致 | 未配置 AI 接口时返回教材原文摘录（不是模型生成），因此**离线状态天然不可能编造**；AI 调用失败自动降级并标注 |

## 三、对话体验

| 能力 | 实现 |
|---|---|
| 上下文与追问 | 保留最近 6 轮对话注入提示词；「它 / 这个 / 接着说 / 再详细些」自动补上当前 3D 选中部位或上一轮主题（`resolveQuery`） |
| 选中部位联动 | 在三维标本上点选某器官后提问，该部位作为检索加权与上下文一并带入 |
| 指出错误能修正 | 界面「这条有误」按钮记录反馈并自动发起纠错轮；提示词规则 5 要求先承认、重新依据片段核对，无法判定时说无法确认，不辩解 |
| 超范围诚实说明 | 明确说「无法给出有教材依据的回答，因此不作答」，并给三条合适建议（换教材术语 / 点选三维部位 / 查参考书或请教教师）；寒暄给友好引导 |

## 四、实用性

| 项 | 情况 |
|---|---|
| 访问方式 | 双击 `start.bat` → `http://127.0.0.1:5173` → 顶栏书本图标。**手机端**：竖屏/窄屏与横屏紧凑模式均有专用悬浮「助教」按钮（固定在顶栏下方，展开右侧知识抽屉时自动让位）。零配置、完全离线可运行，不需要 API Key |
| 运行稳定性 | 语料按 6 个章节分片动态加载，只在首次提问时载入，不影响三维场景启动；不改动原渲染、运镜、拾取与紧凑模式代码；已通过 JS 语法检查、Node 检索自检与浏览器加载烟测 |
| AI 增强（可选） | 配置任意 OpenAI 兼容接口（或 `AI_API_KEY` 走 `/api/ai` 代理）后由模型组织答案；不配置也能完整使用 |
| 试用与反馈 | 界面每条回答有「有帮助 / 这条有误 / 复制」，反馈写入本机 `localStorage`，控制台 `__MALUS__.courseQA.exportFeedback()` 可导出。**真人试用记录见 `docs/试用与反馈记录.md`，未编造** |

## 六、已知限制

1. 教材全文由 OCR 转写，密集表格、复杂公式、图内文字可能有识别误差；关键数据、拉丁学名建议对照原书复核。
2. 教材为扫描件，每页整页图片，无文本层；常规 PDF 提取器无法读取（本项目已实测官方工具崩溃、pypdf 提取 0 字）。
3. 标题层级由 OCR 字号推断，个别小节层级可能与原书不完全一致；出处以「章 + 小节 + 教材页码」为准。
4. `knowledge/植物学（第三版）/` 中的 556 个插图链接指向解析服务云端，公开可访问但长期稳定性不保证；不影响问答文本。
5. 模型增强模式下，输出仍受片段约束，但不能 100% 排除模型误读片段；因此每条回答都保留可展开的原文依据供核对。**离线模式无此风险**。
