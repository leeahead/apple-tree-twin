建议试用任务（每位同学 5 分钟）：

1. 打开顶栏「课程助教问答」，先看说明卡，说出这个助教能答什么、不能答什么。
2. 点一个示例问题，检查回答末尾的教材章节与页码能否在原书找到。
3. 点三维标本上的「气孔」，再问「它有什么作用？」，看是否理解成追问。
4. 故意问一个超范围问题（如「帮我写段代码」），看是否诚实说不知道并给建议。
5. 故意指出「这条回答有误」，看助教是否承认并重新核对。
6. 对一条回答点「有帮助」或「这条有误」，确认反馈被记录。

## 三、反馈采集方式

- 界面：每条回答下方「有帮助 / 这条有误 / 复制」。
- 存储：本机 `localStorage`，键 `malus-courseqa-feedback-v1`，保留最近 200 条，字段 `{ ts, question, verdict }`。
- 导出：浏览器控制台执行

  ```js
  __MALUS__.courseQA.exportFeedback()
  ```

  返回 JSON 数组，可粘贴进本文件表格或另存为 `feedback.json`。
- 说明：反馈只存试用者本机，不上传，不外发。多人试用需分别导出后汇总。
